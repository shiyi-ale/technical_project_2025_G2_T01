# Technical Project 2025 

This repository contains the source code, demo videos, and project materials for a Raspberry Pi based smart car technical project.  
The project focuses on line following, obstacle avoidance, computer vision, and deep learning applications for an autonomous vehicle.

## Project Overview

The smart car is designed to complete several autonomous driving tasks, including:

- Sensor-based line following
- Camera-based line following
- Ultrasonic obstacle avoidance
- Vision-based obstacle avoidance
- Deep learning based object classification and detection

The project combines hardware control, image processing, and machine learning to improve the vehicle's ability to perceive the environment and make movement decisions.
